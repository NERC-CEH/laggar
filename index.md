# laggar

Code for creating matrices of environmental variables at varying lags,
to enable scalar-on-function regression within the mgcv pacakge. The
statistical method follows the method of Miller et al
([2025](https://doi.org/10.48550/arXiv.2508.07915)).

To install the package, use the following code:

    # install.packages("remotes")
    remotes::install_github("NERC-CEH/jsdmstan")
